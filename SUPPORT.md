# Support

Where to go depending on what you need.

| Need | Go to |
| --- | --- |
| How do I..., is this expected, ideas | [Discussions](https://github.com/orgs/scalar-app/discussions) |
| Documentation | [scalar-app/docs](https://github.com/scalar-app/docs) |
| A confirmed bug in a specific repo | That repo's Issues, using the bug report template |
| A feature or integration request | That repo's Issues, using the feature or integration template |
| A security vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| Contributing questions | [CONTRIBUTING.md](CONTRIBUTING.md), then Discussions |

Before opening anything, search Discussions and Issues; many questions already have answers.

There is no paid support and no guaranteed response time. Maintainers are volunteers and answer as they can. Clear reports with versions, steps and logs get answered fastest.
