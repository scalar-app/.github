# Scalar

**Your entire life has an inbox. Scalar turns it into a plan.**

Scalar is open-source productivity infrastructure for email, calendar, school, projects and everything else demanding your attention. It connects the systems you already use into one action layer, so what needs doing shows up as a plan instead of a pile. Cross-platform, self-hosted, AGPL-3.0.

There is no hosted Scalar and none is planned. You run it, on your own machine or a server you already have, and your data stays there. The assistant uses your own model key and is entirely optional: without one, everything else works and the Ask page says so.
